## Quatre couches concentriques

<BlocCode
  langue="text"
  code={`+---------------------------------------+
|              marge (margin)            |
|  +-----------------------------------+ |
|  |         bordure (border)          | |
|  |  +------------------------------+ | |
|  |  |    padding (espace interne)  | | |
|  |  |  +------------------------+  | | |
|  |  |  |       contenu          |  | | |
|  |  |  +------------------------+  | | |
|  |  +------------------------------+ | |
|  +-----------------------------------+ |
+---------------------------------------+`}
/>

`padding` sépare le contenu de la bordure, `margin` sépare la bordure des éléments voisins. Les deux se confondent facilement pour un débutant, alors qu'ils se situent de part et d'autre de la bordure.

## Le piège de la largeur totale

<BlocCode
  langue="css"
  code={`.boite {
  width: 200px;
  padding: 20px;
  border: 5px solid black;
}
/* Largeur totale reellement affichee, par defaut : 200 + 20*2 + 5*2 = 250px */`}
/>

<Avertissement type="attention">
  Par défaut (`box-sizing: content-box`), `width` ne s'applique qu'au contenu : le padding et la bordure s'ajoutent en plus, ce qui surprend souvent en découvrant CSS.
</Avertissement>

## border-box : une largeur totale prévisible

<BlocCode
  langue="css"
  code={`.boite {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 5px solid black;
}
/* Largeur totale : exactement 200px, padding et bordure inclus */`}
/>
