## Colorer le texte et son arrière-plan

<BlocCode
  langue="css"
  code={`p {
  color: white;             /* couleur du texte */
  background-color: navy;   /* couleur de l'arriere-plan de la boite */
}`}
/>

## Taille, graisse et alignement

<BlocCode
  langue="css"
  code={`h1 {
  font-size: 32px;
  font-weight: bold;   /* equivaut a 700 sur l'echelle 100-900 */
  text-align: center;
}`}
/>

<Avertissement type="astuce">
  `font-weight` accepte aussi bien des mots-clés (`normal`, `bold`) qu'une valeur numérique précise (`400`, `700`), utile pour des polices proposant plusieurs graisses intermédiaires.
</Avertissement>
