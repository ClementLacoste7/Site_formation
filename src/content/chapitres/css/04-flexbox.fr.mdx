## Activer Flexbox

<BlocCode
  langue="css"
  code={`.conteneur {
  display: flex;
}`}
/>

Cette seule ligne aligne les enfants directs de `.conteneur` sur une ligne, côte à côte, sans qu'aucun autre réglage ne soit nécessaire pour ce comportement de base.

## Répartir sur l'axe principal

<BlocCode
  langue="css"
  code={`.conteneur {
  display: flex;
  justify-content: center;        /* centre les enfants */
  /* autres valeurs frequentes : flex-start, flex-end, space-between, space-around */
}`}
/>

## Aligner sur l'axe perpendiculaire

<BlocCode
  langue="css"
  code={`.conteneur {
  display: flex;
  align-items: center;   /* centre verticalement, par defaut sur l'axe perpendiculaire */
}`}
/>

<Avertissement type="astuce">
  `justify-content` et `align-items` répondent à des axes différents : le premier pour l'axe principal (horizontal par défaut), le second pour l'axe perpendiculaire. Les confondre est l'une des sources de confusion les plus fréquentes avec Flexbox.
</Avertissement>
