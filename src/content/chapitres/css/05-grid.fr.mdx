## Activer Grid et définir des colonnes

<BlocCode
  langue="css"
  code={`.conteneur {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;   /* trois colonnes de largeur egale */
  gap: 16px;                             /* espace entre les cellules */
}`}
/>

L'unité `fr` (fraction) répartit l'espace disponible : `1fr 1fr 1fr` crée trois colonnes égales, `1fr 2fr` créerait deux colonnes où la seconde prend deux fois plus de place.

<Avertissement type="astuce">
  `repeat(3, 1fr)` produit exactement le même résultat que `1fr 1fr 1fr`, en plus lisible dès que le nombre de colonnes grandit.
</Avertissement>
