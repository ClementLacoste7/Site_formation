## La structure minimale d'un programme Go

<BlocCode
  langue="go"
  code={`package main

import "fmt"

func main() {
    fmt.Println("Bonjour, le monde !")
}`}
/>

`package main` indique qu'il s'agit d'un programme exécutable. `import "fmt"` importe le package standard contenant `Println`. `func main()` est le point d'entrée, exécuté automatiquement au lancement.

## Déclarer des variables

<BlocCode
  langue="go"
  code={`var age int = 25        // declaration explicite avec type
var prenom string = "Alice"
estMajeur := true        // declaration courte, type deduit automatiquement
prix := 19.99

fmt.Println(prenom, "a", age, "ans.")`}
/>

<Avertissement type="info">
  `:=` ne fonctionne qu'à l'intérieur d'une fonction. Pour une variable au niveau global du fichier (en dehors de toute fonction), `var` est obligatoire.
</Avertissement>

## Les types de base

<BlocCode
  langue="go"
  code={`var nombreEntier int = 42
var nombreDecimal float64 = 3.14
var estVrai bool = false
var texte string = "bonjour"

fmt.Printf("%T\\n", nombreEntier) // int
fmt.Printf("%T\\n", nombreDecimal) // float64`}
/>

`%T` dans `fmt.Printf` affiche le type de la valeur fournie, utile pour vérifier ce que Go a déduit automatiquement.

<Avertissement type="attention">
  Go refuse de compiler une variable déclarée mais jamais utilisée. Si `age` n'est lu nulle part après sa déclaration, le programme ne compile tout simplement pas.
</Avertissement>
