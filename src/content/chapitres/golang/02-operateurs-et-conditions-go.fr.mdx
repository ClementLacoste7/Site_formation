## Comparer des valeurs

<BlocCode
  langue="go"
  code={`age := 20
aPermis := true

fmt.Println(age >= 18)             // true
fmt.Println(age >= 18 && aPermis)  // true : les deux doivent etre vraies
fmt.Println(age < 18 || aPermis)   // true : au moins une est vraie
fmt.Println(!aPermis)              // false : inverse la valeur`}
/>

## Les conditions, sans parenthèses

<BlocCode
  langue="go"
  code={`func categoriser(note int) string {
    if note >= 16 {
        return "Excellent"
    } else if note >= 10 {
        return "Admis"
    } else {
        return "Ajourne"
    }
}

fmt.Println(categoriser(18)) // "Excellent"
fmt.Println(categoriser(5))  // "Ajourne"`}
/>

<Avertissement type="info">
  Contrairement à Java ou JavaScript, Go n'exige pas de parenthèses autour de la condition d'un `if`. Les accolades `{}` restent en revanche toujours obligatoires, même pour un bloc d'une seule instruction.
</Avertissement>

## L'instruction d'initialisation dans un if

<BlocCode
  langue="go"
  code={`ages := map[string]int{"Alice": 25, "Bob": 30}

if valeur, existe := ages["Alice"]; existe {
    fmt.Println("Age trouve :", valeur)
} else {
    fmt.Println("Cle absente")
}
// valeur et existe ne sont visibles qu'ici, pas en dehors du if/else`}
/>

Cette syntaxe limite la portée de `valeur` et `existe` au bloc `if`/`else`, évitant de polluer le reste de la fonction avec des variables temporaires.
