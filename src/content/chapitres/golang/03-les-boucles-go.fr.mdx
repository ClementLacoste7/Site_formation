## La boucle for classique

<BlocCode
  langue="go"
  code={`for i := 0; i < 5; i++ {
    fmt.Println(i) // 0, 1, 2, 3, 4
}`}
/>

## for comme équivalent d'un while

<BlocCode
  langue="go"
  code={`energie := 100
tours := 0

for energie > 0 {
    energie -= 30
    tours++
}

fmt.Println(tours) // 4`}
/>

Avec une seule condition (sans initialisation ni incrémentation explicites), `for` se comporte exactement comme un `while` d'un autre langage.

## La boucle infinie

<BlocCode
  langue="go"
  code={`compteur := 0
for {
    compteur++
    if compteur >= 3 {
        break // sort de la boucle
    }
}
fmt.Println(compteur) // 3`}
/>

`for` sans aucune condition répète indéfiniment, jusqu'à rencontrer un `break` explicite.

<Avertissement type="attention">
  Une boucle `for` infinie sans jamais de `break` (ni de condition d'arrêt atteinte) tourne pour toujours et fige le programme.
</Avertissement>

## Parcourir avec for...range

<BlocCode
  langue="go"
  code={`fruits := []string{"pomme", "banane", "cerise"}

for i, fruit := range fruits {
    fmt.Println(i, fruit)
}
// 0 pomme
// 1 banane
// 2 cerise

// Si l'index n'est pas utile :
for _, fruit := range fruits {
    fmt.Println(fruit)
}`}
/>

Le tiret bas `_` ignore explicitement une valeur qu'on ne compte pas utiliser, ici l'index.

## À toi de jouer

  langue="go"
  code={`total := 0

        total += i
    }
}
fmt.Println(total)`}
/>
