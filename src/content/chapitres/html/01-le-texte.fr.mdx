## Un trio, trois rôles distincts

HTML structure le contenu d'une page (ce qui existe : un titre, un paragraphe, une image). CSS lui donne une apparence (couleurs, mise en page). JavaScript la rend interactive (réagir à un clic, modifier le contenu). Ce cours traite exclusivement de HTML ; les deux suivants couvrent CSS puis JavaScript.

<Avertissement type="info">
  Dans les exercices de ce cours, tu écris seulement ce qui irait dans le `&lt;body&gt;` d'une vraie page. Le reste (`&lt;!doctype html&gt;`, `&lt;head&gt;`, encodage des caractères) existe dans toute page réelle, mais reste hors de l'éditeur pour se concentrer sur le contenu.
</Avertissement>

## Une hiérarchie de titres

<BlocCode
  langue="html"
  code={`<h1>Titre principal de la page</h1>
<h2>Un grand titre de section</h2>
<h3>Un sous-titre</h3>`}
/>

Il n'existe qu'un seul `h1` par page en général (le titre principal), puis les niveaux suivants (`h2`, `h3`...) structurent les sections et sous-sections, sans en sauter : un `h3` doit suivre un `h2`, pas directement un `h1`.
