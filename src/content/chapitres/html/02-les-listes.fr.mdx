## Liste non ordonnée : l'ordre n'a pas d'importance

<BlocCode
  langue="html"
  code={`<ul>
  <li>Pommes</li>
  <li>Bananes</li>
  <li>Cerises</li>
</ul>`}
/>

## Liste ordonnée : l'ordre compte

<BlocCode
  langue="html"
  code={`<ol>
  <li>Préchauffer le four</li>
  <li>Mélanger les ingrédients</li>
  <li>Enfourner 20 minutes</li>
</ol>`}
/>

<Avertissement type="astuce">
  Le navigateur numérote automatiquement une `ol` (1, 2, 3...) : jamais besoin d'écrire les numéros soi-même dans le texte de chaque `li`.
</Avertissement>

## Imbriquer une liste

Une liste peut contenir une autre liste, directement à l'intérieur d'un `li` :

<BlocCode
  langue="html"
  code={`<ul>
  <li>Fruits
    <ul>
      <li>Pommes</li>
      <li>Bananes</li>
    </ul>
  </li>
  <li>Légumes</li>
</ul>`}
/>
