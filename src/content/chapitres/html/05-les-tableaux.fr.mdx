## La structure d'un tableau

<BlocCode
  langue="html"
  code={`<table>
  <tr>
    <th>Produit</th>
    <th>Prix</th>
  </tr>
  <tr>
    <td>Clavier</td>
    <td>79,90 €</td>
  </tr>
  <tr>
    <td>Souris</td>
    <td>29,90 €</td>
  </tr>
</table>`}
/>

`table` délimite l'ensemble, chaque `tr` (table row) est une ligne, et chaque cellule d'une ligne est soit `th` (en-tête) soit `td` (donnée).

<Avertissement type="danger">
  Un tableau décrit des données en grille, jamais la mise en page générale d'une page (menu, colonnes, pied de page). Cet usage détourné, courant avant l'arrivée de CSS moderne (voir le cours CSS), perturbe aujourd'hui les lecteurs d'écran et n'a plus aucune raison d'être.
</Avertissement>
