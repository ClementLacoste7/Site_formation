## La structure de base

<BlocCode
  langue="html"
  code={`<form>
  <label for="prenom">Ton prénom</label>
  <input type="text" id="prenom" name="prenom" />
  <button type="submit">Envoyer</button>
</form>`}
/>

## Le lien entre un label et son champ

<Avertissement type="attention">
  Placer un label juste avant un champ dans le code ne crée aucune association réelle. Seule la correspondance entre `for` (sur le label) et `id` (sur le champ) fait le lien : sans elle, cliquer sur le texte du label n'active pas le champ, et un lecteur d'écran ne les relie pas.
</Avertissement>

## Choisir le bon type d'input

<BlocCode
  langue="html"
  code={`<input type="text" />     <!-- texte libre -->
<input type="email" />    <!-- adresse e-mail, validation et clavier adaptes -->
<input type="password" /> <!-- masque la saisie -->
<input type="number" />   <!-- clavier numerique, fleches +/- -->`}
/>
