## La structure minimale d'un programme Java

Contrairement à Python, qui exécute directement un fichier de haut en bas, Java exige que tout code vive à l'intérieur d'une classe, elle-même exécutée par une méthode `main` précise :

<BlocCode
  langue="java"
  code={`public class Bonjour {
    public static void main(String[] args) {
        System.out.println("Bonjour, le monde !");
    }
}`}
/>

Le nom du fichier (`Bonjour.java`) doit correspondre exactement au nom de la classe publique qu'il contient. `System.out.println` affiche une ligne de texte dans la console, l'équivalent du `print()` de Python.

## Déclarer des variables typées

<BlocCode
  langue="java"
  code={`int age = 25;
double prix = 19.99;
boolean estMajeur = true;
char initiale = 'A';
String prenom = "Alice";

System.out.println(prenom + " a " + age + " ans.");`}
/>

<Avertissement type="info">
  Java distingue les types primitifs (`int`, `double`, `boolean`, `char`), stockés directement en mémoire, des types objets comme `String`, qui référencent un objet. Cette distinction a des implications plus tard, notamment pour la comparaison de valeurs.
</Avertissement>

## Les types primitifs les plus courants

<BlocCode
  langue="java"
  code={`int nombreEntier = 42;        // nombre entier
double nombreDecimal = 3.14;  // nombre à virgule flottante
boolean estVrai = false;      // true ou false uniquement
char lettre = 'Z';            // un seul caractère, entre guillemets simples`}
/>

Contrairement à Python où `True` et `False` commencent par une majuscule, Java utilise `true` et `false` entièrement en minuscules.
