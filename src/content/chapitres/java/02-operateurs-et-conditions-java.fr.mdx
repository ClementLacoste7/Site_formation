## Comparer des valeurs

<BlocCode
  langue="java"
  code={`int age = 20;
boolean aPermis = true;

System.out.println(age >= 18);               // true
System.out.println(age >= 18 && aPermis);     // true : les deux doivent etre vraies
System.out.println(age < 18 || aPermis);      // true : au moins une est vraie
System.out.println(!aPermis);                 // false : inverse la valeur`}
/>

## Le piège de == sur les objets

<BlocCode
  langue="java"
  code={`String a = "bonjour";
String b = "bonjour";
String c = new String("bonjour");

System.out.println(a == b);        // true : litteraux partages (pool de chaines)
System.out.println(a == c);        // false : objets distincts en memoire
System.out.println(a.equals(c));   // true : meme contenu`}
/>

<Avertissement type="attention">
  Utilise toujours `.equals()` pour comparer le contenu de deux objets (comme des `String`), jamais `==`. Pour les types primitifs (`int`, `double`, `boolean`), `==` compare bien les valeurs directement, sans ce piège.
</Avertissement>

        return "Ajourne";
    }

System.out.println(categoriser(5));  // "Ajourne"`}
