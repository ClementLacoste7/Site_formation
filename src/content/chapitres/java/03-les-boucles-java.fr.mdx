}`}

## La boucle while

<BlocCode
  langue="java"
  code={`int energie = 100;
int tours = 0;

while (energie > 0) {
    energie -= 30;
    tours++;
}

System.out.println(tours); // 4`}
/>

<Avertissement type="attention">
  Une boucle `while` dont la condition ne devient jamais fausse tourne indéfiniment. Vérifie toujours qu'une valeur utilisée dans la condition change bien à l'intérieur du bloc.
</Avertissement>

## Parcourir un tableau avec for-each

<BlocCode
  langue="java"
  code={`int[] notes = {12, 15, 8, 20};

for (int note : notes) {
    System.out.println(note);
}
// 12
// 15
// 8
// 20`}
/>

`for (int note : notes)` se lit « pour chaque note dans notes » : chaque élément du tableau est donné directement, sans index à gérer.

## À toi de jouer

<BlocCode
  langue="java"
  code={`int total = 0;
for (int i = 1; i <= 5; i++) {
    if (i % 2 == 0) {
        total += i;
    }
}
System.out.println(total);`}
/>
