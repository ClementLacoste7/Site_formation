## Déclarer et utiliser un tableau

<BlocCode
  langue="java"
  code={`int[] notes = {12, 15, 8, 20};

System.out.println(notes[0]);       // 12
System.out.println(notes.length);   // 4 (propriete, pas methode)

notes[1] = 18; // modifie un element existant`}
/>

Contrairement à une `ArrayList`, un tableau a une taille fixe : `notes.length` donne cette taille, comme une propriété (sans parenthèses), pas comme une méthode.

<Avertissement type="attention">
  Accéder à un index inexistant (comme `notes[4]` sur un tableau de taille 4, dont les indices valides vont de 0 à 3) lève une `ArrayIndexOutOfBoundsException` qui arrête le programme si elle n'est pas gérée.
</Avertissement>

## Créer un tableau de taille fixe vide

<BlocCode
  langue="java"
  code={`int[] scores = new int[3]; // tableau de 3 entiers, initialises a 0

scores[0] = 10;
scores[1] = 20;
scores[2] = 30;`}
/>

Un tableau d'entiers créé avec `new int[taille]` initialise automatiquement chaque case à `0` (ou `null` pour un tableau d'objets, `false` pour un tableau de booléens).

## La classe utilitaire Arrays

<BlocCode
  langue="java"
  code={`import java.util.Arrays;

int[] nombres = {5, 2, 8, 1};
Arrays.sort(nombres);
System.out.println(Arrays.toString(nombres)); // [1, 2, 5, 8]`}
/>

`Arrays.sort()` trie le tableau sur place, et `Arrays.toString()` construit une représentation textuelle lisible, bien plus pratique que d'afficher directement le tableau (qui afficherait une référence mémoire peu lisible).
