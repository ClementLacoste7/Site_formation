## Déclarer une méthode

<BlocCode
  langue="java"
  code={`public static int carre(int x) {
    return x * x;
}

System.out.println(carre(5)); // 25`}
/>

Une méthode Java déclare toujours explicitement son type de retour (`int` ici), avant son nom. `static` signifie que la méthode appartient à la classe elle-même, appelable sans créer d'instance, un détail abordé plus en profondeur au chapitre sur les classes.

## Les méthodes void

<BlocCode
  langue="java"
  code={`public static void afficherSalutation(String nom) {
    System.out.println("Bonjour, " + nom + " !");
    // pas de return avec valeur ici : void l'interdit
}

afficherSalutation("Alice"); // affiche "Bonjour, Alice !"`}
/>

<Avertissement type="info">
  Une méthode `void` ne renvoie rien d'utilisable : `int resultat = afficherSalutation("Alice");` provoquerait une erreur de compilation, puisqu'il n'y a aucune valeur à affecter à `resultat`.
</Avertissement>

## La surcharge de méthodes

<BlocCode
  langue="java"
  code={`public static int additionner(int a, int b) {
    return a + b;
}

public static double additionner(double a, double b) {
    return a + b;
}

System.out.println(additionner(2, 3));       // 5 (version int)
System.out.println(additionner(2.5, 3.5));   // 6.0 (version double)`}
/>

Le compilateur choisit automatiquement la bonne version selon le type des arguments fournis à l'appel.
