## Les méthodes courantes de String

<BlocCode
  langue="java"
  code={`String texte = "Bonjour le monde";

System.out.println(texte.length());               // 16
System.out.println(texte.toUpperCase());           // "BONJOUR LE MONDE"
System.out.println(texte.substring(0, 7));         // "Bonjour"
System.out.println(texte.contains("monde"));       // true
System.out.println(texte.replace("monde", "Java")); // "Bonjour le Java"`}
/>

Contrairement à un tableau, `.length()` sur un `String` s'utilise avec des parenthèses : c'est une méthode, pas une propriété.

## L'immuabilité des chaînes

<BlocCode
  langue="java"
  code={`String original = "bonjour";
String modifie = original.toUpperCase();

System.out.println(original); // "bonjour" (inchange)
System.out.println(modifie);  // "BONJOUR" (nouvel objet)`}
/>

<Avertissement type="info">
  Aucune méthode de `String` ne modifie l'objet d'origine : chacune renvoie un nouvel objet. Si tu veux conserver le résultat, il faut l'assigner explicitement, comme `original = original.toUpperCase();`.
</Avertissement>

## Construire une chaîne efficacement avec StringBuilder

<BlocCode
  langue="java"
  code={`StringBuilder resultat = new StringBuilder();

for (int i = 1; i <= 3; i++) {
    resultat.append(i).append(", ");
}

System.out.println(resultat.toString()); // "1, 2, 3, "`}
/>

`.append()` modifie `resultat` sur place, sans créer un nouvel objet à chaque appel, contrairement à une concaténation répétée avec `+`.
