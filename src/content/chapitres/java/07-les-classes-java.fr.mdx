## Définir une classe

<BlocCode
  langue="java"
  code={`public class CompteBancaire {
    private double solde;

    public CompteBancaire(double soldeInitial) {
        this.solde = soldeInitial;
    }

    public double deposer(double montant) {
        this.solde += montant;
        return this.solde;
    }

    public double getSolde() {
        return this.solde;
    }
}`}
/>

`private` empêche tout accès direct à `solde` depuis l'extérieur de la classe : on doit passer par les méthodes publiques `deposer()` et `getSolde()`, un principe appelé encapsulation.

## Créer et utiliser une instance

<BlocCode
  langue="java"
  code={`CompteBancaire compte = new CompteBancaire(100);
System.out.println(compte.deposer(50)); // 150
System.out.println(compte.getSolde());  // 150

// compte.solde = 1000000; // erreur de compilation : solde est private`}
/>

Chaque instance a son propre `solde`, indépendant des autres instances de `CompteBancaire`.

## Getters et setters

<BlocCode
  langue="java"
  code={`public class CompteBancaire {
    private double solde;

    public CompteBancaire(double soldeInitial) {
        this.solde = soldeInitial;
    }

    public double getSolde() {
        return solde;
    }

    public void setSolde(double nouveauSolde) {
        if (nouveauSolde >= 0) {
            this.solde = nouveauSolde;
        }
    }
}`}
/>

<Avertissement type="astuce">
  Un setter peut valider la nouvelle valeur avant de l'accepter, ici en refusant un solde négatif. Cette validation serait impossible à garantir si `solde` était directement modifiable depuis l'extérieur.
</Avertissement>
