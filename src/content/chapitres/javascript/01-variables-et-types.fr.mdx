## Déclarer une variable

<BlocCode
  langue="javascript"
  code={`let age = 25;

<Avertissement type="astuce">

## Construire une chaîne avec un template literal

Concaténer du texte et des variables avec `+` devient vite pénible. Un **template literal** (délimité par des accents graves) insère directement des variables dans un texte :

<BlocCode
  langue="javascript"
  code={`const prenom = "Alice";
const age = 25;
const message = \`\${prenom} a \${age} ans\`;
console.log(message);`}
/>

`${...}` insère directement le résultat d'une expression dans le texte, sans avoir besoin d'interrompre la chaîne avec des `+`.
