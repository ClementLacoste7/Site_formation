## Comparer des valeurs

<BlocCode
  langue="javascript"
  code={`console.log(5 > 3);   // true
console.log(5 === 5); // true
console.log(5 !== 3); // true
console.log("5" == 5);  // true  : == convertit les types
console.log("5" === 5); // false : === refuse, les types different`}
/>

<Avertissement type="attention">
  Utilise toujours `===` et `!==`, jamais `==` ni `!=`. L'égalité faible convertit silencieusement les types avant de comparer, ce qui produit des résultats surprenants comme `null == undefined` (true) ou `0 == ""` (true).
</Avertissement>

## Combiner des conditions

<BlocCode
  langue="javascript"
  code={`const age = 20;
const aPermis = true;

console.log(age >= 18 && aPermis); // true : les deux doivent etre vraies
console.log(age < 18 || aPermis);  // true : au moins une est vraie
console.log(!aPermis);             // false : inverse la valeur`}
/>

## Brancher l'exécution avec if / else if / else

<BlocCode
  langue="javascript"
  code={`function categoriser(note) {
  if (note >= 16) {
    return "Excellent";
  } else if (note >= 10) {
    return "Admis";
  } else {
    return "Ajourne";
  }
}

console.log(categoriser(18)); // "Excellent"
console.log(categoriser(12)); // "Admis"
console.log(categoriser(5));  // "Ajourne"`}
/>
