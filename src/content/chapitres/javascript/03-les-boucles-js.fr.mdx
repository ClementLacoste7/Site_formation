## La boucle for classique

<BlocCode
  langue="javascript"
  code={`for (let i = 0; i < 5; i++) {
  console.log(i); // 0, 1, 2, 3, 4
}`}
/>

Trois parties séparées par des points-virgules : l'initialisation (`let i = 0`), la condition testée avant chaque tour (`i < 5`), et l'incrémentation exécutée après chaque tour (`i++`).

## La boucle while

<BlocCode
  langue="javascript"
  code={`let energie = 100;
let tours = 0;

while (energie > 0) {
  energie -= 30;
  tours++;
}

console.log(tours); // 4`}
/>

`while` répète son bloc tant que la condition reste vraie. Utile quand on ne connaît pas à l'avance le nombre exact de répétitions.

<Avertissement type="attention">
  Une boucle `while` dont la condition ne devient jamais fausse tourne indéfiniment et fige la page. Vérifie toujours qu'une valeur utilisée dans la condition change bien à l'intérieur du bloc.
</Avertissement>

## Parcourir un tableau avec for...of

<BlocCode
  langue="javascript"
  code={`const fruits = ["pomme", "banane", "cerise"];

for (const fruit of fruits) {
  console.log(fruit);
}
// "pomme"
// "banane"
// "cerise"`}
/>
