## Déclarer une fonction

  langue="javascript"

  return \`Bonjour, \${nom} !\`;
}

console.log(saluer("Alice")); // "Bonjour, Alice !"`}

## Les fonctions fléchées

<BlocCode
  langue="javascript"
  code={`const carre = (x) => x * x;
console.log(carre(5)); // 25

const addition = (a, b) => {
  const resultat = a + b;
  return resultat;
};
console.log(addition(2, 3)); // 5`}
/>

Avec des accolades, une fonction fléchée a besoin d'un `return` explicite comme une fonction classique. Sans accolades, l'expression après `=>` est renvoyée directement.

## Paramètres par défaut

<BlocCode
  langue="javascript"
  code={`function saluer(nom = "visiteur") {
  return \`Bonjour, \${nom} !\`;
}

console.log(saluer());        // "Bonjour, visiteur !"
console.log(saluer("Bob"));   // "Bonjour, Bob !"`}
/>

<Avertissement type="info">
  Une fonction sans `return` renvoie toujours `undefined`, même si elle affiche quelque chose avec `console.log` à l'intérieur. Afficher une valeur et la renvoyer sont deux choses différentes.
</Avertissement>
