## Créer et modifier un tableau

<BlocCode

## Transformer avec map et filter

<BlocCode
  langue="javascript"
  code={`const nombres = [1, 2, 3, 4, 5];

const doubles = nombres.map((n) => n * 2);
console.log(doubles); // [2, 4, 6, 8, 10]

const pairs = nombres.filter((n) => n % 2 === 0);
console.log(pairs); // [2, 4]`}
/>

<Avertissement type="astuce">
  `map` et `filter` ne modifient jamais le tableau d'origine : elles renvoient un nouveau tableau. C'est ce qui permet de les enchaîner en toute sécurité, comme `nombres.filter(...).map(...)`.
</Avertissement>

## Agréger avec reduce

<BlocCode
  langue="javascript"
  code={`const nombres = [1, 2, 3, 4, 5];

const somme = nombres.reduce((total, n) => total + n, 0);
console.log(somme); // 15`}
/>

`reduce` prend une fonction `(accumulateur, element) => nouvelAccumulateur` et une valeur initiale (ici `0`), puis parcourt le tableau en mettant à jour l'accumulateur à chaque étape.
