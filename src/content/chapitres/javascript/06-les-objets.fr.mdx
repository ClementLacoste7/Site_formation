## Créer un objet et accéder à ses propriétés

<BlocCode
  langue="javascript"
  code={`const personne = {
  nom: "Alice",
  age: 25,
  ville: "Lyon"
};

console.log(personne.nom);       // "Alice"
console.log(personne["age"]);    // 25

personne.age = 26;         // modifie une propriete existante
personne.email = "a@x.fr"; // ajoute une nouvelle propriete`}

## La déstructuration

<BlocCode
  langue="javascript"
  code={`const personne = { nom: "Alice", age: 25, ville: "Lyon" };

const { nom, age } = personne;
console.log(nom); // "Alice"
console.log(age); // 25`}
/>

<Avertissement type="astuce">
  La déstructuration `const { nom } = objet` est très utilisée pour extraire directement des propriétés, notamment comme paramètre de fonction : `function afficher({ nom, age }) { ... }`.
</Avertissement>

## Objets et méthodes

Un objet peut aussi contenir des fonctions, appelées méthodes :

<BlocCode
  langue="javascript"
  code={`const compte = {
  solde: 100,
  deposer(montant) {
    this.solde += montant;
    return this.solde;
  }
};

console.log(compte.deposer(50)); // 150`}
/>

`this` désigne l'objet sur lequel la méthode est appelée : ici, `compte`.
