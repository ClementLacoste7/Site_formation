## Intercepter une erreur

<BlocCode
  langue="javascript"
  code={`try {
  const resultat = JSON.parse("ceci n'est pas du JSON");
  console.log(resultat);
} catch (erreur) {
  console.log("Erreur interceptee :", erreur.message);
}
console.log("Le script continue normalement");`}
/>

Sans `try/catch`, une erreur non interceptée arrête l'exécution du script à cet endroit précis.

## Lever ses propres erreurs

<BlocCode
  langue="javascript"
  code={`function diviser(a, b) {
  if (b === 0) {
    throw new Error("Division par zero impossible");
  }
  return a / b;
}

try {
  console.log(diviser(10, 0));
} catch (erreur) {
  console.log("Erreur :", erreur.message);
}`}
/>

<Avertissement type="info">
  `throw new Error("message")` crée et lève un objet d'erreur en une seule instruction. Le `catch` le plus proche qui englobe l'appel de la fonction interceptera cette erreur.
</Avertissement>
