## Une variable, un nom pour une valeur

Écrire un programme consiste presque toujours à manipuler des valeurs : un âge, un nom, un prix. Une **variable** donne un nom à une valeur, pour pouvoir la réutiliser plus loin sans la réécrire :

<BlocCode langue="python" code={`age = 25
prenom = "Alice"
print(prenom, "a", age, "ans")`} />

Le signe `=` n'est pas un test d'égalité ici : c'est une **affectation**. Il associe le nom à gauche à la valeur à droite.

## Quatre types que tu croiseras partout

<BlocCode
  langue="python"
  code={`entier = 25
decimal = 3.14
texte = "Bonjour"
booleen = True

print(type(entier))   # <class 'int'>
print(type(decimal))  # <class 'float'>
print(type(texte))    # <class 'str'>
print(type(booleen))  # <class 'bool'>`}
/>

- **int** : un nombre entier, positif ou négatif, sans partie décimale.
- **float** : un nombre à virgule (appelé « flottant »).
- **str** : une chaîne de caractères, toujours entourée de guillemets simples ou doubles.
- **bool** : une valeur logique, seulement `True` ou `False` (avec ces majuscules précises).

<Avertissement type="astuce">
  `type()` renvoie le type réel d'une valeur : un réflexe utile dès qu'un comportement surprend, avant même de chercher plus loin.
</Avertissement>

## Construire un texte avec une f-string

Concaténer du texte et des variables devient vite pénible avec des virgules ou des `+`. Une **f-string** (chaîne « formatée ») insère directement des variables dans un texte, entre accolades :

<BlocCode langue="python" code={`prenom = "Alice"
age = 25
message = f"{prenom} a {age} ans"
print(message)`} />

Le `f` juste avant les guillemets active ce comportement : sans lui, `{prenom}` s'afficherait tel quel, comme du texte brut.
