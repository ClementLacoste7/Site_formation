## Les opérateurs arithmétiques

<BlocCode
  langue="python"
  code={`print(7 + 3)   # 10  addition
print(7 - 3)   # 4   soustraction
print(7 * 3)   # 21  multiplication
print(7 / 3)   # 2.333...  division (renvoie toujours un float)
print(7 // 3)  # 2   division entiere (arrondie vers le bas)
print(7 % 3)   # 1   modulo : le reste de la division entiere
print(7 ** 2)  # 49  puissance`}
/>

<Avertissement type="astuce">
  Le modulo (`%`) sert très souvent à tester la parité d'un nombre : `nombre % 2 == 0` est vrai si et seulement si `nombre` est pair.
</Avertissement>

## Les opérateurs de comparaison

Une comparaison renvoie toujours un booléen, jamais autre chose :

<BlocCode
  langue="python"
  code={`print(5 == 5)   # True   egalite
print(5 != 3)   # True   difference
print(5 > 3)    # True   strictement superieur
print(5 >= 5)   # True   superieur ou egal
print(5 < 3)    # False  strictement inferieur`}
/>

<Avertissement type="attention">
  `==` teste une égalité, `=` affecte une valeur à une variable (chapitre précédent). Les confondre est l'une des erreurs les plus fréquentes en début d'apprentissage.
</Avertissement>

## Combiner des conditions

Trois opérateurs logiques combinent des expressions booléennes entre elles :

<BlocCode
  langue="python"
  code={`age = 25
possede_billet = True

print(age >= 18 and possede_billet)   # True : les deux doivent etre vraies
print(age >= 18 or possede_billet)    # True : au moins une suffit
print(not possede_billet)              # False : inverse le booleen`}
/>
