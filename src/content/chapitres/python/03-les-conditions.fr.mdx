## Exécuter un bloc seulement si une condition est vraie

<BlocCode
  langue="python"
  code={`age = 16

if age >= 18:
    print("Majeur")
else:
    print("Mineur")`}
/>

Les deux points `:` annoncent le début d'un bloc, et l'**indentation** (généralement 4 espaces) délimite ce qui lui appartient. Une ligne qui revient au niveau précédent signale la fin du bloc, sans qu'aucun mot-clé ne soit nécessaire pour le fermer.

<Avertissement type="attention">
  Une erreur d'indentation n'est pas qu'une question de style en Python : elle change littéralement quelles lignes appartiennent à quel bloc, et peut provoquer une erreur ou un comportement inattendu.
</Avertissement>

## Enchaîner plusieurs cas avec elif

<BlocCode
  langue="python"
  code={`note = 14

if note >= 16:
    print("Excellent")
elif note >= 12:
    print("Bien")
elif note >= 10:
    print("Passable")
else:
    print("Insuffisant")`}
/>

Python teste chaque condition dans l'ordre et exécute le premier bloc dont la condition est vraie, puis ignore tous les suivants : l'ordre des `elif` a donc de l'importance dès que plusieurs conditions pourraient être vraies en même temps.
