## for : répéter un nombre de fois connu

<BlocCode
  langue="python"
  code={`for i in range(5):
    print(i)
# Affiche 0, 1, 2, 3, 4 (5 valeurs, jamais 5 lui-meme)`}
/>

`for` fonctionne aussi directement sur une collection, sans passer par `range` :

<BlocCode
  langue="python"
  code={`fruits = ["pomme", "banane", "cerise"]
for fruit in fruits:
    print(fruit)`}
/>

## while : répéter tant qu'une condition est vraie

<BlocCode
  langue="python"
  code={`compteur = 0
while compteur < 5:
    print(compteur)
    compteur = compteur + 1
# Affiche 0, 1, 2, 3, 4 : identique au for range(5) ci-dessus`}
/>

<Avertissement type="danger">
  Sans la ligne `compteur = compteur + 1`, la condition `compteur < 5` resterait vraie indéfiniment : la boucle ne s'arrêterait jamais. C'est l'erreur la plus fréquente avec while, absente par construction avec for.
</Avertissement>

## Quand choisir l'un ou l'autre

<BlocCode
  langue="text"
  code={`for   : le nombre de repetitions est connu a l'avance (une liste, un intervalle)
while : la fin depend d'une condition qui n'est pas connue a l'avance`}
/>
