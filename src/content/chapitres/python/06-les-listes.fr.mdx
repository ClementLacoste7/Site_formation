## Créer et indexer une liste

<BlocCode
  langue="python"
  code={`fruits = ["pomme", "banane", "cerise"]

print(fruits[0])    # pomme (le premier element, indice 0)
print(fruits[-1])   # cerise (le dernier element)
print(len(fruits))  # 3 (le nombre d'elements)`}
/>

<Avertissement type="astuce">
  Un indice négatif compte depuis la fin : -1 est toujours le dernier élément, -2 l'avant-dernier, quelle que soit la longueur de la liste.

## Modifier une liste

<BlocCode
  langue="python"
  code={`fruits = ["pomme", "banane"]

fruits.append("cerise")     # ajoute a la fin : ["pomme", "banane", "cerise"]
fruits.remove("banane")     # supprime cette valeur : ["pomme", "cerise"]

print("pomme" in fruits)    # True : teste la presence d'une valeur`}
/>

## Parcourir et filtrer une liste

Combiner une boucle `for` (chapitre précédent) avec une liste permet de construire une nouvelle liste à partir d'une autre :

<BlocCode
  langue="python"
  code={`nombres = [1, 2, 3, 4, 5, 6]
pairs = []

for nombre in nombres:
    if nombre % 2 == 0:
        pairs.append(nombre)

print(pairs)  # [2, 4, 6]`}
/>
