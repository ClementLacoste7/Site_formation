## Indexer et découper une chaîne

Une chaîne se comporte comme une liste de caractères, avec la même syntaxe d'indexation et de slicing :

<BlocCode
  langue="python"
  code={`mot = "Bonjour"

print(mot[0])     # B
print(mot[-1])    # r
print(mot[0:3])   # Bon (indices 0, 1, 2 : la fin est exclue)
print(len(mot))   # 7`}
/>

## Des méthodes qui renvoient toujours une nouvelle chaîne

<BlocCode
  langue="python"
  code={`phrase = "  Bonjour Le Monde  "

print(phrase.strip())          # "Bonjour Le Monde" (espaces aux extremites retires)
print(phrase.lower())          # "  bonjour le monde  "
print(phrase.strip().split())  # ["Bonjour", "Le", "Monde"] (decoupe sur les espaces)
print(phrase.replace("Le", "Un"))  # "  Bonjour Un Monde  "`}
/>

<Avertissement type="attention">
  Aucune de ces méthodes ne modifie `phrase` elle-même : une chaîne est **immuable**. `phrase.lower()` sans réaffectation (`phrase = phrase.lower()`) ne change rien à la variable `phrase`.
</Avertissement>

## Assembler une chaîne à partir d'une liste

<BlocCode
  langue="python"
  code={`mots = ["Bonjour", "Le", "Monde"]
print(" ".join(mots))  # "Bonjour Le Monde"`}
/>

`join` fait l'inverse de `split` : il assemble une liste de chaînes en une seule, séparée par le texte sur lequel il est appelé (un espace, ici).
