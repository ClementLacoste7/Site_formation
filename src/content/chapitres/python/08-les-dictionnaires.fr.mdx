## Une collection indexée par clé, pas par position

<BlocCode
  langue="python"
  code={`ages = {"Alice": 25, "Bob": 40}

print(ages["Alice"])   # 25
ages["Carol"] = 32     # ajoute une nouvelle entree

print("Bob" in ages)   # True : teste la presence d'une cle`}

## Éviter une erreur avec get()

<Avertissement type="attention">
  `ages["Inconnu"]` lève une erreur (`KeyError`) si la clé n'existe pas. `ages.get("Inconnu", 0)` renvoie `0` dans ce cas, sans jamais planter.
</Avertissement>

<BlocCode
  langue="python"
  code={`ages = {"Alice": 25}

print(ages.get("Alice", 0))    # 25 : la cle existe
print(ages.get("Inconnu", 0))  # 0 : valeur par defaut, aucune erreur`}
/>

## Parcourir un dictionnaire

<BlocCode
  langue="python"
  code={`ages = {"Alice": 25, "Bob": 40}

for nom, age in ages.items():
    print(nom, "a", age, "ans")`}
