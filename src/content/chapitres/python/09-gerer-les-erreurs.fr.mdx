## Intercepter une erreur précise

<BlocCode
  langue="python"
  code={`try:
    resultat = 10 / 0
except ZeroDivisionError:
    print("Division par zero evitee")
    resultat = None

print("Le programme continue normalement")`}
/>

Le bloc `try` contient l'instruction risquée. Si l'erreur indiquée après `except` survient, Python exécute ce bloc à la place de laisser le programme s'arrêter, puis continue normalement après.

<Avertissement type="attention">
  Cibler `except ZeroDivisionError` plutôt qu'un `except` générique évite de masquer une erreur totalement différente (une faute de frappe dans un nom de variable, par exemple), qui devrait au contraire apparaître clairement plutôt que d'être avalée silencieusement.
</Avertissement>

## Plusieurs types d'erreurs, plusieurs except

<BlocCode
  langue="python"
  code={`valeurs = ["10", "0", "abc"]

for valeur in valeurs:
    try:
        print(100 / int(valeur))
    except ZeroDivisionError:
        print("Impossible de diviser par zero")
    except ValueError:
        print(f"'{valeur}' n'est pas un nombre valide")`}
/>
