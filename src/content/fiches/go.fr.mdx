questions:
  - question: "Quelle est la différence entre var age int = 25 et age := 25 ?"
    reponse: "Les deux déclarent une variable valant 25, mais := déduit automatiquement le type et ne fonctionne qu'à l'intérieur d'une fonction, contrairement à var utilisable aussi au niveau global."
  - question: "Pourquoi Go n'a-t-il qu'un seul mot-clé de boucle, for ?"
    reponse: "for peut être utilisé sous plusieurs formes (avec compteur, comme un while avec une seule condition, ou sans condition pour une boucle infinie), rendant un mot-clé while séparé superflu."
  - question: "Quelle est la différence entre un tableau ([3]int) et un slice ([]int) ?"
    reponse: "Un tableau a une taille fixe incluse dans son type. Un slice est flexible et redimensionnable avec append(), dont le résultat doit toujours être réassigné."
  - question: "Pourquoi de nombreuses fonctions Go renvoient-elles deux valeurs, comme (resultat, err) ?"
    reponse: "Pour signaler la réussite ou l'échec d'une opération sans système d'exceptions : la convention est de vérifier systématiquement err avec if err != nil."
  - question: "Pourquoi len(\"café\") renvoie-t-il 5, pas 4 ?"
    reponse: "len() compte des octets, pas des caractères visibles. Le é est encodé sur deux octets en UTF-8. Pour compter les caractères réels (runes), utiliser for range."
  - question: "Comment un struct implémente-t-il une interface en Go ?"
    reponse: "De façon implicite : dès qu'un type possède toutes les méthodes requises par l'interface, il l'implémente automatiquement, sans mot-clé implements."
  - question: "Que renvoie l'accès à une clé absente d'une map ?"
    reponse: "La valeur zéro du type des valeurs (comme 0 pour int), sans erreur. L'idiome valeur, ok := maMap[cle] permet de distinguer une clé absente d'une clé présente valant zéro."
  - question: "Quelle est la différence entre une erreur normale (error) et un panic ?"
    reponse: "Une erreur normale signale un problème attendu, à vérifier avec if err != nil. Un panic signale une situation vraiment exceptionnelle et interrompt le programme, sauf récupération avec recover()."
